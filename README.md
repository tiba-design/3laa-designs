# 3laa Designs — بوابة طلبات تصميم وتنسيق الملازم التعليمية

بوابة إلكترونية مخصصة للمدرسين لتجهيز ملفات الملازم التعليمية وتقديم طلبات التصميم والتنسيق البصري وإرسالها مباشرة عبر الواتساب.

## الرابط المباشر للموقع
- **الموقع الرسمي:** https://tiba-design.github.io/3laa-designs/

## أبرز المميزات
- **دليل التجهيز قبل البدء:** خطوات واضحة لتجهيز بيانات المدرس، ملف الوورد (`.docx`)، الشعار والصور عالية الجودة، وتفضيلات التنسيق.
- **نموذج طلب متكامل:** اختيار الباقة، الخدمات المطلوبة، الألوان، اتجاه الصفحة، وإرفاق أسماء الملفات.
- **معاينة فورية وإرسال للواتساب:** توليد رسالة منسقة تلقائياً مع إمكانية النسخ أو الحفظ كملف نصي أو الفتح المباشر على الواتساب.
